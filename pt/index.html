Gerador de IBAN

    Como funciona

    Escolha um país (o detetado a partir do navegador vem pré-selecionado), indique uma quantidade e clique em Gerar. Cada IBAN é construído segundo o formato nacional do país (comprimento, código de banco, código de balcão, número de conta) e depois são calculados os dígitos de controlo: o nacional, quando o país usa um, e o internacional do IBAN (ISO 7064, mod 97-10). O resultado passa nos validadores de IBAN.

    Os códigos de banco utilizados são reais: BNP Paribas, ING, Santander, Rabobank, UniCredit, Deutsche Bank. É isso que dá credibilidade ao IBAN. O número de conta, esse, é aleatório: nenhum IBAN gerado corresponde a uma conta existente.

    Perguntas frequentes

    Os IBAN gerados são válidos?

    Sim, estruturalmente. Cada IBAN respeita o formato nacional do país escolhido (ISO 13616), os dígitos de controlo internacionais (ISO 7064, mod 97-10) e, para a Bélgica, Espanha, França, Itália, Portugal, Finlândia, Eslovénia e Estónia, os dígitos de controlo nacionais.

    Correspondem a contas bancárias reais?

    Não. O código de banco é real para que o formato seja realista, mas o número de conta é aleatório. Nenhuma transferência pode chegar a um IBAN gerado aqui.

    Para que serve um gerador de IBAN?

    Para testar: formulários de pagamento, regras de validação, importações de ficheiros SEPA, conjuntos de dados de demonstração ou de pré-produção. Usar um IBAN gerado para enganar alguém é fraude e é ilegal.

    Os meus dados são enviados para algum lado?

    Não. Tudo é calculado no seu navegador, em JavaScript. Sem servidor, sem rastreadores, sem publicidade, sem registo.

    Quantos IBAN se podem gerar de uma vez?

    Até 1000 por lote, exportáveis em TXT ou CSV com o país e o banco.

    Aviso: os IBAN gerados respeitam o formato nacional e os dígitos de controlo, mas não correspondem a nenhuma conta bancária real. Qualquer utilização fraudulenta é ilegal.
